# docs/external-docs/ — مستنداتِ سرویس‌های بیرونی

هر وقت دستیار برای وصل‌شدن به یک سرویسِ بیرونی مستنداتش را لازم داشته باشد، از تو می‌خواهد آن را اینجا بگذاری — یک فایلِ PDF، یک صفحهٔ ذخیره‌شده، یا حتی متنی که از سایتِ سرویس کپی کرده‌ای.

لازم نیست خودت آن را بفهمی. فقط پیدایش کن و اینجا بگذار؛ خواندن و نوشتنِ اتصال کارِ دستیار است.

هیچ رمز و کلیدی اینجا نمی‌آید — آن‌ها در `secrets/` می‌مانند.
