# سؤال‌های دورِ چهارم — سندِ محصول

> جوابِ دورِ قبل ثبت شد. تصمیمت دربارهٔ **دو ملاکِ اصلی** برای هر نوع پوشاک درست است و در سند اعمال شد — ولی همان تصمیم یک چیزِ تازه را باز می‌کند که باید حل شود، و آن سؤالِ ۲۵ است.
>
> نکته‌ات دربارهٔ عدد هم پذیرفته شد و سند عوض شد. توضیحش در `docs/living/prd.md` بخشِ «چرا عددِ دقیق گفته نمی‌شود» آمده است.
>
> سه سؤال، همه کوتاه. **هر ردیفی که خالی بماند یعنی پیش‌فرض قبول است.**
