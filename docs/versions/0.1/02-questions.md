# سؤال‌های دورِ اول — هستهٔ ایده

> **چطور جواب بدهی:** جوابت را در ستونِ آخر، در همان ردیف، بنویس. لازم نیست همه را جواب بدهی — **هر ردیفی که خالی بگذاری، یعنی «پیش‌فرضِ پیشنهادی خوب است».** هیچ سؤالی کار را متوقف نمی‌کند.
>
> جواب کوتاه کافی است. اگر خواستی توضیحِ بیشتری بدهی، هرچقدر دوست داشتی بنویس.
>
> وقتی تمام شد، در گفت‌وگو بنویس «جواب دادم».
