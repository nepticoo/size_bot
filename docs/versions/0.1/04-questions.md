# سؤال‌های دورِ سوم — سندِ محصول

> پیش‌نویسِ سندِ محصول در `docs/living/prd.md` نوشته شد. این پنج سؤال چیزهایی است که برای کامل شدنش لازم است — همه‌شان تصمیمِ کسب‌وکاری‌اند، نه فنی.
>
> جواب را در ستونِ آخر بنویس. **هر ردیفی که خالی بماند یعنی پیش‌فرض قبول است.** هیچ‌کدام کار را متوقف نمی‌کند.
>
> سؤالِ ۲۲ از بقیه مهم‌تر است، چون کیفیتِ جوابی که مشتری می‌بیند به آن بستگی دارد.
