# سؤال‌های دورِ ششم — مدلِ داده

> پیش‌نویسِ مدلِ داده در `docs/living/data-model.md` نوشته شد: نُه «چیز» که محصول باید به خاطر بسپارد، نسبتشان با هم، و قاعده‌هایی که همیشه باید درست بمانند.
>
> این چهار سؤال از آن دسته سؤال‌های حوصله‌سربری است که همیشه ارزشش را دارد — چون هر کدامشان اگر حالا جواب داده نشود، در روزِ دوم کارِ دوباره درست می‌کند.
>
> جواب را در ستونِ آخر بنویس. **هر ردیفی که خالی بماند یعنی پیش‌فرض قبول است.**
