# docs/living/ — مستنداتِ زنده

این‌ها همیشه وضعِ **فعلیِ** محصول را نشان می‌دهند و در جای خودشان ویرایش می‌شوند.

- به واقع `prd.md` — محصول چه می‌کند و برای که. (در `/prd` نوشته می‌شود.)
- به واقع `data-model.md` — چیزهایی که محصول به خاطر می‌سپارد و نسبتشان با هم. (در `/data-model`.)
- به واقع `ux.md` — صفحه‌ها، مسیرهای کاربر و تم. (در `/ux`.)
- به واقع `dependencies.md` — تنها سندِ سرویس‌های بیرونی. (در `/deps`.)
- به واقع `test-scenarios.md` — سناریوهایی که «کار می‌کند» را تعریف می‌کنند. **قبل از ساخت** نوشته می‌شوند. (در `/scenarios`.)
- به واقع `architecture.md` — مرجعِ فنی. لازم نیست بخوانی. (در `/plan`.)
- به واقع `roadmap.md` — فهرستِ چیزهایی که عمداً به بعد موکول شده‌اند. **فهرستِ کارها نیست**؛ کارهای نسخه‌ای که در حالِ ساخت است در `docs/versions/<نسخه>/checklist.md` است.
