# existing_product/ — کدهای قبلیِ محصول (اختیاری)

اگر از قبل برای محصولت کد، پروتوتایپ، یا اسکریپت‌هایی داری (مثلاً یک برنامهٔ جنگو، فست‌اِی‌پی‌آی، یا کدهای پایتون)، فایل‌های اصلیِ کدت را داخلِ همین پوشه بگذار.

## نکته‌های مهم:
1. **پوشه‌های سنگین را کپی نکن:** لطفاً پوشه‌هایی مثل `node_modules`، `venv`، `.git`، یا فایل‌های حجیم ویدیویی/دیتابیس را داخل این پوشه نگذار. فقط کدهای منبع کافی است.
2. **دستیار چطور از این پوشه استفاده می‌کند؟** وقتی دستورِ `/idea-core` را اجرا می‌کنی، دستیار به‌صورت خودکار وجود کدهای این پوشه را تشخیص می‌دهد و فایل‌های ساختاری (مدل‌های داده، روت‌ها/APIها، پکیج‌ها و معماری) را بررسی می‌کند تا قابلیت‌ها و منطقِ موجود را استخراج کند.
3. اگر کد قبلی نداری، لازم نیست به این پوشه دست بزنی؛ خالی رهایش کن.
